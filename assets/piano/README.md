# Muestras de piano

Grabaciones del **Salamander Grand Piano V3** de Alexander Holm (Yamaha C5),
publicadas bajo licencia [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
Fuente original: <https://archive.org/details/SalamanderGrandPianoV3>.
Estos archivos son la versión en MP3 que distribuye el proyecto [Tone.js](https://github.com/Tonejs/audio).

Hay una muestra cada tres semitonos (Do, Re♯, Fa♯, La) entre Do3 y Re♯6;
las notas intermedias se obtienen cambiando la velocidad de reproducción.
